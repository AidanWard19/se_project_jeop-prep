# JEOP PREP
Jeop Prep is a daily Jeopardy practice web app built with React. Each day, the app uses a date-based seed to deterministically select three unique challenges from a local database of real Jeopardy questions spanning decades of the show: a Daily Double, a Final Jeopardy question, and a Daily Category — a full set of clues from a randomly chosen category. Questions reset automatically every day, so there's always something new to test your knowledge. Users can type their answers, get instant correct/incorrect feedback, and reveal the answer if they're stumped. The app is entirely self-contained with no external API dependencies, and is live at https://AidanWard19.github.io/se_project_jeop-prep.
